Project Description

The Social Media Impact on Teen Mental Health Dashboard is a data visualization and analytics project designed to analyze how social media usage affects the mental health of teenagers. This dashboard provides meaningful insights into factors such as screen time, social media addiction, anxiety, depression, sleep quality, academic performance, and emotional well-being among teens.
The project uses interactive visualizations to identify trends, behavioral patterns, and correlations between social media activity and mental health conditions. By analyzing demographic factors such as age group, gender, daily usage hours, and platform preferences, the dashboard helps users better understand the positive and negative effects of social media on teenagers.
The dashboard enables stakeholders such as parents, teachers, researchers, and policymakers to explore mental health indicators through dynamic charts, filters, KPIs, and reports. The goal of this project is to raise awareness, support data-driven decision-making, and promote healthier digital habits among teenagers.

Key Features
Analysis of social media usage patterns among teenagers
Mental health indicators (stress, anxiety, depression, sleep issues)
Interactive charts and KPI cards
Demographic-based analysis (age, gender, usage time)
Trend analysis and behavioral insights
Dynamic filtering for better data exploration


Technologies Used
Power BI for dashboard development
Microsoft Excel / CSV dataset for data processing
DAX for calculated measures and KPIs
Data visualization and analytics techniques
